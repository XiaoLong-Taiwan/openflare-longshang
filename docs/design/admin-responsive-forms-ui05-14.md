# 管理清單與憑證表單調整

本次範圍為 UI05–10／12／14 指定的管理任務、使用者、網站憑證表單、反向代理清單與 HTML／WAF 編輯器。儲存庫未找到編號對照規格，因此以下以實際頁面與行為列出交付內容，不能視為逐編號驗收。

## 手機清單

- 任務類型保留名稱、類型、佇列、重試上限、參數數量、狀態及執行操作；名稱按鈕可開啟完整詳細資料。
- 排程保留名稱、關聯任務、Cron、啟用狀態及編輯／刪除操作；Payload 仍可透過編輯視窗查看。
- 執行紀錄保留任務名稱、識別碼、狀態、建立時間、耗時、重試及兩行結果摘要；名稱按鈕開啟完整結果與紀錄。
- 使用者保留暱稱、帳號、ID、電子郵件、最近登入及狀態摘要，維持詳細資料、編輯及狀態切換。
- 反向代理保留網站名稱、完整網域摘要、來源摘要、狀態、設定及刪除操作。
- 桌面維持分欄表格。使用者註冊與更新時間在大型螢幕顯示，其他尺寸可在詳細資料查看。

## 工具列與表單

- 任務頁籤可橫向捲動，執行紀錄與反向代理分頁可換行；使用者篩選、分頁與重新整理改善手機操作區域，空清單顯示至少一頁。
- 使用者搜尋欄具有可存取名稱，ID 與電子郵件提供對應輸入鍵盤提示。
- 憑證手動匯入與編輯共用路由內的欄位元件，名稱、備註、憑證及私鑰均連結 label 與控制項。
- 驗證失敗顯示欄位錯誤，透過 `aria-invalid`、`aria-describedby` 與警示角色連結錯誤；ACME 申請補齊名稱、主網域、DNS 帳戶及備註錯誤。
- 檔案匯入的名稱及兩個檔案為必填，名稱與備註限制長度；匯入視窗可在有限視窗高度內捲動。
- 檔案匯入面板在頁籤切換時保持掛載，隱藏非作用中面板；返回時保留檔案欄位，清除操作仍會重設兩個檔案。
- 指定頁面沒有既有批次操作。本次未新增批次 API 或操作，也未修改位於 nodes、Cloudflare 與檔案管理的批次回饋。

## 編輯器

- HTML 工作區最小總高度為 520px，編輯／預覽內容至少保留 280px，工具列換行時仍有可用內容區域。
- WAF 編輯器最小總高度為 640px，畫布至少保留 360px；標題、狀態與工具列可換行，短視窗以頁面捲動保留操作。
- 未修改共用 ui、layout、nodes、dashboard 或共享 changelog，沒有 API、資料庫或版本號變更。

## 驗證

- 新增憑證匯入、申請、編輯的空值驗證回歸測試，檢查 label、錯誤關聯及不發出無效 API 請求。
- 新增使用者摘要與具名操作回歸測試；沿用 WAF 編輯器與網站詳細頁的既有測試。
- responsive/forms 整合審查涵蓋共用元件、主版面、節點與儀表板差異；以上各節原本描述的是管理清單與表單子範圍。
- 新增檔案匯入頁籤往返及清除回歸測試，驗證檔案欄位與畫面狀態一致。
- 完整 Vitest、TypeScript、全 frontend ESLint、四語系鍵值檢查與靜態匯出均納入整合驗證。
- `make code-check` 因目前 Windows 環境缺少可執行的 Go／Bash 工具鏈而中止，未宣稱全專案檢查通過。
- Browser 外掛不可用，專案亦未安裝 Playwright；未執行真實瀏覽器的手機／桌面畫面、螢幕鍵盤及高度驗證。jsdom 測試不代表實際 CSS 排版驗收。
