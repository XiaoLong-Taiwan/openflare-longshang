# 手機編輯與管理操作

- HTML 工作區在窄螢幕以「HTML 編輯器／即時預覽」切換顯示，保留編輯內容；桌面保持雙欄，分隔線支援滑鼠、觸控筆與觸控拖曳，以及方向鍵和 Home／End 調整。
- 桌面搜尋入口使用可聚焦按鈕，支援 Enter 與空白鍵開啟搜尋對話框。
- 網站詳細頁的頁籤可橫向捲動，避免較長翻譯或數量文字撐開頁面。
- 設定首頁在手機使用單欄，較寬螢幕維持兩欄。
- 憑證清單在手機顯示摘要卡片，包含名稱、狀態、到期時間、來源、備註及原有操作；桌面維持表格。編輯、轉換、續期及刪除確認沿用既有流程。
- 共用文字輸入與多行輸入在手機使用 16px 字級，文字輸入保留至少 44px 高度。存取日誌篩選支援搜尋鍵提示，狀態碼與節點 ID 使用數字鍵盤；時間範圍在手機直向排列。

新增工作區文案放在 `frontend/messages/fragments/html-workspace.*.json`，涵蓋簡體中文、繁體中文、英文與俄文，由既有腳本合併。
