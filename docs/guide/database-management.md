# 資料管理

管理員可在 `/admin/database` 使用「總覽」及「資料表瀏覽」兩個分頁。

## 總覽

容量與連線顯示伺服器回傳的資料庫大小、資料表數量、連線數、類型、版本與名稱／路徑。桌面將容量與維護、匯出操作並排，手機改為單欄。

快取管理按下「載入快取管理」後才讀取磁碟快取用量與設定。儲存策略沿用既有接口；立即清空快取必須經確認對話框確認。開啟頁面、載入狀態或重新整理都不會執行清理。

維護區按下「載入／重新整理維護預覽」後，才查詢過期任務與快取項目數量。成功取得預覽並至少勾選一項操作後，才能開啟執行確認。確認內容只列出已勾選項目，確認後沿用既有背景維護工作；可到工作管理查看執行進度。預覽不是即時推送，執行前可手動更新。

備份匯出仍由管理員手動啟動，沿用既有下載接口與檔名。

總覽的重新整理更新容量資訊及已載入的快取，不會額外查詢資料表或維護預覽。

## 資料表瀏覽

首次切入才載入資料表清單，再讀取選取資料表的分頁內容。重新整理只更新資料表清單與目前頁面，不重新讀取總覽。表格可在自身區域水平捲動，選單與分頁操作在小螢幕可換行。

來回切換兩個分頁會保留資料、選取表格、頁碼與快取表單，避免僅因切換而重複查詢。離開整個頁面後重新進入，會重新載入。

此次調整只使用既有資料與 API，不新增容量估算、清理排程或資料庫結構。
