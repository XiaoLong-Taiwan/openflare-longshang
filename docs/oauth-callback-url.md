# OAuth 認證源回呼網址

管理台的 OAuth 認證源新增與編輯視窗會顯示唯讀的「回呼 / 重新導向 URL」，可點選「複製網址」登記至 OAuth 供應商。

- OIDC、Google、Discord 與 GitHub 共用 `/login`，不依認證源名稱產生不同路徑。
- 網址沿用系統設定服務取得的 `server_address`，移除結尾斜線後附加 `/login`，並保留設定中的路徑前綴。
- 設定成功載入且 `server_address` 未設定或為空時，顯示目前瀏覽器的 origin 加上 `/login`。正式環境應確認 `server_address` 與對外位址一致。
- 設定載入期間或載入失敗時停用複製，避免將尚未確認的網址登記至供應商。
- 複製成功或失敗皆顯示提示；瀏覽器不支援剪貼簿或拒絕授權時，可選取欄位內容手動複製。

視窗支援窄螢幕直向排列與內容捲動，新增文案提供繁體中文、簡體中文、英文與俄文。
